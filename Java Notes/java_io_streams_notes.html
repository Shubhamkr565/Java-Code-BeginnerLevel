Section 01
What is a Stream?
A stream is an abstraction representing a flow of data between a program and an external source or destination.
📁
Program ↔ File
Read from or write to files on disk using file-oriented stream classes.
🧠
Program ↔ Memory
Transfer data in-memory using byte array or string streams.
🌐
Program ↔ Network
Send and receive data across a network using socket streams.
🖥️
Program ↔ Device
Interact with console, keyboard, printers, and other peripherals.
📦
Package Location All stream classes live in java.io and java.nio. Data must first be represented as either bytes (8-bit) or characters (16-bit Unicode) before transfer.
☕ Java IO Class Hierarchy
💡
Quick Rule If the class name ends in Stream → Byte-oriented. Ends in Reader/Writer → Character-oriented.
Section 02
Character Streams
Used exclusively for text data — Strings, CSV, text files. Internally converts characters to bytes using an encoding like UTF-8.

✍️ FileWriter

Writes character data directly to a file. Simple but lacks cross-platform line-separator support.

Constructor (overwrite)
new FileWriter("abc.txt")
Constructor (append)
new FileWriter("abc.txt", true)

Methods

write(int ch)write(char[] ch)write(String s) flush()close()
⚠️
Limitation FileWriter requires manual line-separator insertion ("\n" or "\r\n"), which varies by OS. Use BufferedWriter with newLine() instead.
Java
// ✅ Recommended: try-with-resources (auto flush + close)
try (FileWriter fw = new FileWriter("abc.txt", true)) {
    fw.write(100);            // writes char 'd' (ASCII 100)
    fw.write("Hello World\n"); // writes string + newline
    char[] ch = {'a', 'b', 'c'};
    fw.write(ch);            // writes char array
} catch (IOException e) {
    e.printStackTrace();
}
// close() auto-calls flush() — no explicit flush() needed!

📖 FileReader

Reads character data from a file, character by character. Handles Unicode natively.

int read()int read(char[])void close()
ℹ️
Return Value read() returns the character as an int (Unicode value). Returns -1 at End of File (EOF).
Java — Two Approaches
// Approach 1: char-by-char (safe for all sizes)
try (FileReader fr = new FileReader("abc.txt")) {
    int i;
    while ((i = fr.read()) != -1) {
        System.out.print((char) i);
    }
}

// Approach 2: char[] bulk read (faster, not for huge files)
try (FileReader fr = new FileReader(f)) {
    char[] buf = new char[(int) f.length()];
    fr.read(buf);
    System.out.println(new String(buf));
}

📝 BufferedWriter

Wraps a Writer object to add buffering and the cross-platform newLine() method. Never communicates with the file directly.

BufferedWriter → FileWriter → File on Disk
Java
try (BufferedWriter bw = new BufferedWriter(new FileWriter("a2.txt"))) {
    bw.write(100);                    // 'd'
    bw.newLine();                    // ✅ OS-independent newline!
    bw.write("Welcome to Java");
    bw.newLine();
    char[] ch = {'a', 'b', 'c'};
    bw.write(ch);
} catch (IOException e) { e.printStackTrace(); }
✅
Auto Close Chain Closing BufferedWriter automatically closes the underlying FileWriter too.

📚 BufferedReader

The most enhanced reader class. Reads data line by line (not char-by-char) for superior performance. Also works for keyboard input via System.in.

int read()int read(char[])String readLine()void close()
Java — File & Keyboard Input
// Reading from a file line by line
try (BufferedReader br = new BufferedReader(new FileReader("abc.txt"))) {
    String line;
    while ((line = br.readLine()) != null) {
        System.out.println(line);  // readLine() returns null at EOF
    }
}

// Reading from keyboard (User Input)
try (BufferedReader br = new BufferedReader(new InputStreamReader(System.in))) {
    System.out.print("Enter name: ");
    String name = br.readLine();
    System.out.print("Enter salary: ");
    double sal = Double.parseDouble(br.readLine());
    System.out.println(name + " earns " + (sal + 1000));
}

🖨️ PrintWriter — Most Enhanced Writer

Unlike FileWriter and BufferedWriter, PrintWriter can write any primitive type directly — int, boolean, double, char — without manual conversion.

write(100)
Writes the character 'd' (ASCII 100)
FileWriter / BufferedWriter behavior
print(100)
Writes the integer 100 as text
PrintWriter behavior
Java
// PrintWriter with append mode via FileWriter chain
try (PrintWriter pw = new PrintWriter(new FileWriter("a3.txt", true))) {
    pw.write(100);          // → 'd'
    pw.println(100);        // → 100\n
    pw.println("Welcome!"); // → Welcome!\n
    pw.println(true);        // → true\n
    pw.println('a');         // → a\n
    pw.println(50.55);      // → 50.55\n
}

Section 03
Byte Streams
Handle raw binary data — images, videos, audio, serialized objects. Every single byte matters.
⚡ Real-Life Analogy
Think of Byte Streams like electricity — you don't see meaning, it is a raw signal the machine understands. Images, videos, and audio are NOT readable text; they are binary data where every single bit matters.
📥
FileInputStream
Reads bytes from a file. Used for images, videos, audio, binary files. read() returns -1 at EOF.
📤
FileOutputStream
Writes raw bytes to a file. Does NOT support write(String) or newLine() — bytes only.
🚀
BufferedInputStream
Reads a large block into a memory buffer (8 KB default), drastically reducing disk access operations.
💾
BufferedOutputStream
Stores writes in a buffer; flushes to disk only when buffer is full or flush() is called.
🪣 Buffered Streams Analogy
Without buffer: You walk to the water tank every time you need one glass — very slow.
With buffer: You fill an 8-litre bucket once and use it repeatedly — much faster!
BufferedInputStream internally maintains a buffer of 8 KB.

📋 Code: Copy an Image File

Java — Optimized with Buffers
try (
    BufferedInputStream  bis = new BufferedInputStream(new FileInputStream("img.jpg"));
    BufferedOutputStream bos = new BufferedOutputStream(new FileOutputStream("img2.jpg"))
) {
    int data;
    while ((data = bis.read()) != -1) {
        bos.write(data);
    }
    System.out.println("File copied successfully!");
} catch (IOException e) { e.printStackTrace(); }
// BufferedInputStream reduces disk reads by buffering 8192 bytes at a time

Section 04
Serialization
Converting an object from RAM into a byte stream so it can be stored in a file or sent over a network.
🔄 Serialization / Deserialization Flow
🧳 Real-Life Analogy
Object = Clothes. Serialization = Packing into a suitcase. File = Suitcase.
You convert the object into a portable form. Deserialization = Unpacking — restoring the original content.

🔑 The Serializable Interface

  • Lives in java.io.Serializable
  • A marker interface — no methods to implement
  • Only objects of classes that implement Serializable can be serialized
  • Attempting to serialize a non-serializable object → NotSerializableException
  • String, all Wrapper classes, arrays, most Collection classes already implement it

📦 ObjectOutputStream — Serialization

void writeObject(Object o)
Java — A.java + SerializeDemo
// A.java — must implement Serializable
public class A implements Serializable {
    private static final long serialVersionUID = 1L;
    int i = 10;
    void funA() { System.out.println(i); }
}

// Serialization
A a1 = new A();
a1.i = 22;  // change state
try (ObjectOutputStream oos = new ObjectOutputStream(new FileOutputStream("abc.ser"))) {
    oos.writeObject(a1);         // serialize object
    oos.writeObject("Chitkara"); // String is Serializable
    oos.writeObject(10);         // autoboxed to Integer
}
System.out.println("Serialized!");
⚠️
Order Matters! Serialize 3 objects → Deserialize in the same order. Wrong order = ClassCastException.

🔓 ObjectInputStream — Deserialization

Object readObject()
Java — Deserialization
try (ObjectInputStream ois = new ObjectInputStream(new FileInputStream("abc.ser"))) {
    A      a1      = (A)      ois.readObject(); // downcast required
    String msg     = (String) ois.readObject();
    int    x       = (Integer)ois.readObject();
    a1.funA(); // works! state was restored
} catch (Exception e) { e.printStackTrace(); }
// Note: Constructor is NOT called during deserialization!

🏎️ Efficient Serialization with Collections

Instead of writing objects one-by-one, group them in a List and call writeObject() once — far fewer file operations!

Java — Serialize a List<Student>
List<Student> students = new ArrayList<>();
students.add(new Student(10, "Raj",  780));
students.add(new Student(11, "Aman", 680));

// ONE write — much faster than 5 individual writeObject() calls
try (ObjectOutputStream oos = new ObjectOutputStream(new FileOutputStream("students.ser"))) {
    oos.writeObject(students);
}

// ONE read
try (ObjectInputStream ois = new ObjectInputStream(new FileInputStream("students.ser"))) {
    List<Student> list = (ArrayList<Student>) ois.readObject();
    for (Student s : list) System.out.println(s);
}

🕸️ Object Graph

When you serialize an object, all objects reachable from it are also serialized automatically. This set of connected objects is called the Object Graph.

Java — Object Graph Example
class Dog implements Serializable { Cat c = new Cat(); }
class Cat implements Serializable { Rat r = new Rat(); }
class Rat implements Serializable { }

// Serializing Dog → also saves Cat AND Rat automatically
// If ANY class in the graph is NOT Serializable → NotSerializableException
// Fix: either implement Serializable, or mark field as transient
🚨
Rule Every class in the Object Graph MUST implement Serializable, or you must mark the reference as transient to exclude it from serialization.
Section 05
transient & serialVersionUID
Control exactly what gets saved during serialization.

🔇 transient Keyword

📝 Analogy — Filling a Form
Name: saved ✅ | Address: saved ✅ | Password: NOT saved ❌
The transient keyword marks a field as "do not serialize this value."
Field TypeSerialized?Value after Deserialization
Normal instance field int i = 10;✅ YesSaved value (10)
transient String pwd = "abc";❌ NoDefault value (null)
static int j = 20;❌ No (class level)Re-loaded at class load time (20)
static transient int x;❌ No effectstatic already not serialized
transient final int x = 10;Technically excludedRe-initialized at construction (10)
Java — transient Demo
public class A implements Serializable {
    private static final long serialVersionUID = 1L;
    int            i        = 10;    // → saved as-is
    static int     j        = 20;    // → not saved (class-level)
    transient String password = "12345"; // → not saved → null after deserialization
}
// Output after deserialize:
//   i = 10, j = 20 (reloaded), password = null

🔢 serialVersionUID

A unique version ID stored with serialized data. JVM uses it during deserialization to verify the class structure hasn't changed incompatibly.

Class v1 serialized → Class modified → Deserialize attempt → UID mismatch? → InvalidClassException ❌
Java — Best Practice
class Student implements Serializable {
    private static final long serialVersionUID = 1L; // Always define manually!
    // Change to 2L when class structure changes incompatibly
}
// If you don't define it: JVM auto-generates based on class structure
// → any code change regenerates it → old serialized files become invalid!

Section 06
Serialization & Inheritance
How Serializable behavior is inherited and what happens when a parent class is NOT Serializable.
Case 1: Parent IS Serializable
Child is automatically Serializable
No need to implement it again
Both parent & child fields are saved
Like inheriting a VIP pass
Case 2: Parent is NOT Serializable
Child can still implement Serializable
Only child fields are saved
Parent fields restored via constructor
Parent must have a no-arg constructor
Java — Case 2: Non-Serializable Parent
class Animal {          // NOT Serializable — must have no-arg constructor
    int age = 2;
    Animal() {}         // ← REQUIRED! else InvalidClassException
}

class Dog extends Animal implements Serializable {
    private static final long serialVersionUID = 1L;
    String name = "tommy";
}

// Serialize: d.age=4, d.name="Rocky"
// After Deserialization:
//   d.name = "Rocky"  ← saved from serialization
//   d.age  = 2        ← re-initialized from Animal() constructor (not saved!)
//
🚨
Important Rule If the parent is non-Serializable, it must have a zero-argument constructor. JVM calls it during deserialization to recreate the parent object. Missing it causes java.io.InvalidClassException.
Section 07
StreamTokenizer
Automatically breaks a stream of text into typed tokens — words, numbers, and symbols — without manual string splitting.
👩‍🏫 Teacher Analogy
Sentence: Java is easy 100 times
Tokens: Javaiseasy 100times
StreamTokenizer does this splitting automatically!

🔧 Constructor & Key Fields

Java — Setup
StreamTokenizer st = new StreamTokenizer(new FileReader("data.txt"));

// Key Fields:
int    st.ttype; // type of current token
String st.sval;  // value if token is a WORD
double st.nval;  // value if token is a NUMBER

// Constants:
StreamTokenizer.TT_EOF    // -1  End Of File
StreamTokenizer.TT_EOL    // '\n' End Of Line
StreamTokenizer.TT_NUMBER // -2  numeric token
StreamTokenizer.TT_WORD   // -3  word token

📊 Default Behavior

InputToken TypeAccess Via
Alphabetic charactersTT_WORDst.sval
DigitsTT_NUMBERst.nval
SpacesIgnored—
NewlinesIgnored (unless configured)—
Symbols + = etc.Returned directly (char value)(char) st.ttype

📋 Basic Example

Java — Tokens: words, numbers, symbols
// File: "A + B = 100"
try (FileReader fr = new FileReader("data.txt")) {
    StreamTokenizer st = new StreamTokenizer(fr);
    while (st.nextToken() != StreamTokenizer.TT_EOF) {
        if      (st.ttype == StreamTokenizer.TT_WORD)   System.out.println("WORD: "   + st.sval);
        else if (st.ttype == StreamTokenizer.TT_NUMBER) System.out.println("NUM:  "   + st.nval);
        else                                                System.out.println("SYM:  "   + (char) st.ttype);
    }
}
// Output: WORD: A | SYM: + | WORD: B | SYM: = | NUM: 100.0

Task: Find Topper from CSV-style File ▼

File: Rohit: 850, Aman: 900, Karan: 760

Java
try (FileReader fr = new FileReader("data.txt")) {
    StreamTokenizer st = new StreamTokenizer(fr);
    st.whitespaceChars(':', ':');  // ignore colons
    st.whitespaceChars(',', ',');  // ignore commas
    String topper = "";
    double highest = Double.MIN_VALUE;
    while (st.nextToken() != StreamTokenizer.TT_EOF) {
        if (st.ttype == StreamTokenizer.TT_WORD) {
            String name = st.sval;
            st.nextToken();
            if (st.nval > highest) { highest = st.nval; topper = name; }
        }
    }
    System.out.println("Topper: " + topper + " (" + highest + ")");
}
