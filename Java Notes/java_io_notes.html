📁 File Class in Java
KEY IDEA File class ≠ file data.
It only stores path and metadata — not the actual content!

Belongs to java.io package. Used to know characteristics of files/folders on disk.

🏗 Constructors
① new File("path/to/file.txt") — absolute or relative path
② new File("C:/data", "test.txt") — parent dir as String
③ new File(fileObj, "test.txt") — parent dir as File object
⚠ REMEMBER File f = new File("abc.txt") does NOT create a physical file!
Use f.createNewFile() to actually create it.
🔧 Important Methods
exists() → Does path exist on disk?
createNewFile() → Creates empty file; returns false if already exists
mkdir() → Creates directory (fails if parent missing)
mkdirs() → Creates nested folders (no failure!)
delete() → Removes file or empty directory
isFile() / isDirectory() → Type check
length() → Size in bytes (0 for directories)
list() → String[] of file names in directory
listFiles() → File[] with full paths
getName() / getAbsolutePath() / getParent()
// Create folder1/myfile.txt File folder = new File("folder1"); folder.mkdir(); File file = new File("folder1", "myfile.txt"); file.createNewFile(); // wrapped in try-catch

✍️ Character-Oriented Streams

Used for text data only — Strings, text files, CSV. Uses encoding (UTF-8) internally.

FileWriter
// Creates file if not exists. Append mode with true. FileWriter fw = new FileWriter("abc.txt", true); fw.write("Hello Java\n"); fw.flush(); // guarantee last char saved fw.close();
LIMITATION FileWriter needs manual \n or \r\n for new lines — OS dependent! Use BufferedWriter.newLine() instead.
FileReader
FileReader fr = new FileReader("abc.txt"); int i; while ((i = fr.read()) != -1) { // returns -1 at EOF System.out.print((char) i); }
BufferedWriter ⭐

Never communicates directly with file — wraps a Writer object.

BufferedWriter bw = new BufferedWriter( new FileWriter("abc.txt")); bw.write("Hello"); bw.newLine(); // OS-independent line separator ✅ bw.close(); // auto-flushes too
BufferedReader ⭐

Main advantage: read line by line instead of char by char.

BufferedReader br = new BufferedReader( new FileReader("abc.txt")); String line; while ((line = br.readLine()) != null) { // null = EOF System.out.println(line); }
PrintWriter ⭐⭐ (Most Enhanced)

Can write any primitive type directly!

PrintWriter pw = new PrintWriter( new FileWriter("a3.txt", true)); pw.println(100); // writes "100" pw.println(true); // writes "true" pw.println(50.55); // writes "50.55" // write(100) → writes 'd' | println(100) → writes "100"
TIP Always use try-with-resources! Java auto-flushes and closes the stream — no explicit flush/close needed.
CONSOLE INPUT new BufferedReader(new InputStreamReader(System.in))
→ Used to read user input from keyboard (old-school alternative to Scanner).

🔢 Byte-Oriented Streams

Handle raw binary data — images, audio, video, objects. Every single bit matters!

FileInputStream / FileOutputStream
// Copy an image using FileInputStream + FileOutputStream FileInputStream fis = new FileInputStream("img.jpg"); FileOutputStream fos = new FileOutputStream("img2.jpg"); int i; while ((i = fis.read()) != -1) fos.write(i); fis.close(); fos.close();
Buffered Byte Streams (Optimized)
// 8KB internal buffer — MUCH faster for large files try (BufferedInputStream bis = new BufferedInputStream(new FileInputStream("img.jpg")); BufferedOutputStream bos = new BufferedOutputStream(new FileOutputStream("img2.jpg"))) { int data; while ((data = bis.read()) != -1) bos.write(data); }
PrintStream

System.out is a PrintStream object! Writes primitives as bytes to file/console.

📦 Serialization & Deserialization
MUST KNOW To serialize, the class MUST implement java.io.Serializable (marker interface — no methods!).
Otherwise → NotSerializableException at runtime!
Key Methods
oos.writeObject(obj) → Serialize object to stream
ois.readObject() → Deserialize (returns Object — needs downcast)
⚠ IMPORTANT During deserialization, the constructor is NOT called! JVM recreates object directly from byte data.
serialVersionUID
private static final long serialVersionUID = 1L; // Version ID stored with serialized data. // If class changes + ID changes → InvalidClassException on deserialization. // Best practice: always define manually!
transient Keyword
transient String password = "12345"; // This field will NOT be serialized! // After deserialization → password = null (default value) // Common uses: passwords, OTPs, derived/cached values, temp data
transient + static → No effect (static already not serialized)
transient + final → No effect (final re-initialized on creation)

🌳 Object Graph & Inheritance Rules
Serialization + Inheritance
CaseSituationWhat Happens
Case 1 Parent implements Serializable Child is automatically Serializable (inherited!) ✅
Case 2 Parent NOT Serializable, Child IS Child serialized OK. On deserialization, JVM calls parent's zero-arg constructor to rebuild parent. Parent's state = default values.
CRITICAL RULE If parent is non-serializable, it MUST have a zero-arg constructor — otherwise java.io.InvalidClassException!
Efficient Serialization with Collections
// ❌ Slow: serialize 5 objects one by one = 5 file accesses oos.writeObject(s1); oos.writeObject(s2); ... oos.writeObject(s5); // ✅ Fast: serialize the whole list = 1 file access! List<Student> list = new ArrayList<>(); list.add(s1); list.add(s2); ... oos.writeObject(list); // ArrayList implements Serializable ✅

🔍 StreamTokenizer

In java.io. Reads a stream and breaks it into tokens automatically — words, numbers, symbols.

Key Fields & Constants
st.ttype → type of current token
st.sval → String value (if WORD token)
st.nval → double value (if NUMBER token)
TT_EOF / TT_EOL / TT_NUMBER / TT_WORD
Basic Usage Pattern
StreamTokenizer st = new StreamTokenizer(new FileReader("data.txt")); while (st.nextToken() != StreamTokenizer.TT_EOF) { if (st.ttype == StreamTokenizer.TT_WORD) System.out.println("Word: " + st.sval); else if (st.ttype == StreamTokenizer.TT_NUMBER) System.out.println("Number: " + st.nval); else System.out.println("Symbol: " + (char)st.ttype); }
Configuration Methods
eolIsSignificant(true) → detect end-of-line as TT_EOL
slashSlashComments(true) → ignore // comments
slashStarComments(true) → ignore /* ... */ comments
whitespaceChars(',', ',') → treat comma as separator
wordChars('@', '@') → treat @ as part of word (email parsing)
quoteChar('"') → treat quoted string as single token
DEFAULT BEHAVIOR Alphabets → words | Numbers → numeric | Spaces → ignored | Symbols → returned as ttype char

📋 Quick Reference Cheatsheet
Golden Rules to Remember 🏆
  • → Always use try-with-resources — auto close + flush
  • → BufferedReader = fastest reader | PrintWriter = most powerful writer
  • → Serializable class = always define serialVersionUID
  • → transient = don't serialize this field (passwords, temp data)
  • → Serialize collections = 1 writeObject(list) is better than N writeObject() calls
  • → File class ≠ file content — it's just path + metadata
  • → read() returns -1 at EOF — always check!
MODERN ALTERNATIVES Java NIO (java.nio.file.Files), Scanner, try-with-resources, Java Streams API — StreamTokenizer is legacy but great for learning!
